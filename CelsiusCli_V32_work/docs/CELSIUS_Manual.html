CELSIUS V32 Technical Manual

CELSIUS V32 Soil-Crop-Mulch Model Manual

This document reformulates the CELSIUS V32 implementation as a process manual in the spirit of a model reference document. The equations are inferred from the generated VB.NET code, organized by process, and linked to the governing methods and the database tables that feed each block.

V32 revision — September 2026. This manual is tied to CelsiusCli_V32_work and to the Access/VBA sources in celsius_audit_new/access_objects. It describes the implementation and is not an independent formal specification.
Primary Control Flow SimulationControlClass.ReadParameters and Simulation()
Database Pattern SQLite input tables mirroring the historical Access schema
Model Scope Daily soil-water-crop-mulch model with optional daily nitrogen balance

1. Positioning

CELSIUS is organized around simulation units. Each unit selects one climate forcing, one soil, one technical management, one initial condition set, one option set, and one simulation window. The runtime loops over SimUnitList, instantiates the control object, loads all dependent data, simulates day by day, and writes both summary and daily outputs.

2.4 Biomass, CO2 Response, and Grain Yield

V32 first reads a station-level fallback concentration from ListPAnnexes.CO2c. When Codcc = "0", it searches CO2Yearly for the simulation start year and uses that annual value; if the year is absent, it keeps the fallback and writes a warning. When Codcc <> "0", the yearly lookup is skipped.

Spatial and temporal scope. CO2Yearly is indexed by year only and has no idDclim. Its value is therefore identical for every site with the same start year. The lookup occurs once during initialization and is not refreshed during a multi-year run. Only the fallback in ListPAnnexes can vary by station.
CO2fact_i = 2 - exp( ln(2 - alphaCO2_i) * (CO2c - 350) / (600 - 350) ) Calibration points: CO2fact_i(350 ppm) = 1 CO2fact_i(600 ppm) = alphaCO2_i Intercepted radiation: raint_i,j = 0.95 * ParSurRg * Rg_j * [1 - exp(-k_i * LAI_i,j)] Temperature response: Ftemp_i,j = 1 - ((Tmoy_j - tcopt_i) / (tcmin_i - tcopt_i))^2 if Tmoy_j <= tcopt_i Ftemp_i,j = 1 - ((Tmoy_j - tcopt_i) / (tcmax_i - tcopt_i))^2 if Tmoy_j > tcopt_i Ftemp_i,j = max(Ftemp_i,j, 0) Biomass increment: dBiom_i,j = CO2fact_i * WSfact_i,j * PlantPReducFact * [Ebmax_i * raint_i,j - 0.0815 * raint_i,j^2] * Ftemp_i,j / 100 Biom_i,j = Biom_i,j-1 + dBiom_i,j N uptake implied by biomass growth: NCvE_i = NCvEmin_i + (NCvEmax_i - NCvEmin_i) * alphaN_i Nuptake_i,j = dBiom_i,j / NCvE_i At stage 4 onset: Vitmoy_i = 100 / Nbjgrain_i * sum(dBiom_i over the grain-setting window) Ngrains_i = int(Cgrain_i * Vitmoy_i + Cgrainv0_i) During grain filling: IR_i,j = min(Vitircarb_i * (j - JourDrp_i + 1), IRmax_i) Grain_i,j = min(Biom_i,j * IR_i,j, P1grainMax_i * Ngrains_i / 100)

CO2fact is the only direct CO₂ term in the current implementation. It multiplies daily biomass growth. Its effects on N uptake, grain number and yield are indirect through biomass. No separate direct CO₂ response is applied to LAI, phenology, transpiration, stomatal conductance or water-use efficiency.

2.7 Soil Water Balance

Layer aggregation: TAW = (1 / Ztotsol) * sum_c [ (hcc_c - hmin_c) * da_c * epc_c / 10 ] TEW = (hcc_1 - hmin_1) * da_1 * Zsurf / 10 Soil evaporation: Eos_j = EoSM_j - Eomulch_j Esol_j = Eos_j * ContrainteWSurf_j / SeuilEvap if ContrainteWSurf_j < SeuilEvap Esol_j = Eos_j otherwise Esol_j = min(Stsurf_j-1, Esol_j) Surface store: Stsurf_j = min(Stsurf_j-1 + precip_j, TEW) - Esol_j - min(Zsurf / Zrac_j, 1) * Transpi_j ContrainteWSurf_j = Stsurf_j / TEW Rooted zone: Strac_j = min(precip_j + Strac_j-1 + Deltazrac_j * TAW, Zrac_j * TAW) - E_Srac_j - Transpi_j E_Srac_j = Esol_j * min(1, Zrac_j / Zsurf) Non-rooted rootable zone: Dr_j = bil_j - TAW * (Zracmax - Zrac_j) if bil_j > TAW * (Zracmax - Zrac_j) Stnonrac_j = max(0, bil_j) otherwise Deep zone and bottom drainage: Stprofond_j = min(Stprofond_j-1 + Dr_j, TAW * (Ztotsol - Zracmax)) Drprofmax_j = max(Stprofond_j-1 + Dr_j - TAW * (Ztotsol - Zracmax), 0) Water stress: ContrainteW_j = Strac_j / (TAW * Zrac_j) if Zrac_j > 0 ContrainteW_j = 1 otherwise

2.8 Water Stress Pathways

In CELSIUS, water stress is distributed across the model rather than implemented as a standalone module. The soil water balance produces control variables that are then reused by emergence, LAI growth, biomass accumulation, mixed-canopy transpiration, and drought-induced mortality logic.

Primary soil control variables: ContrainteWSurf_j = Stsurf_j / TEW ContrainteW_j = Strac_j / (TAW * Zrac_j) if Zrac_j > 0 ContrainteW_j = 1 otherwise Emergence gate: ContrainteHlevee_j = False if Stger_j >= 0.14 * TAW * Zger ContrainteHlevee_j = True if Stger_j <= 0.10 * TAW * Zger Leaf expansion stress: TurfacH_i,j = 1 if ContrainteW_j > 1 - SeuilTurg_i TurfacH_i,j = ContrainteW_j / (1 - SeuilTurg_i) otherwise Turfac_i,j = min(TurfacH_i,j, TurfacN_i,j) Biomass stress: WSfactH_i,j = 1 if ContrainteW_j > 1 - SeuilWS_i WSfactH_i,j = ContrainteW_j / (1 - SeuilWS_i) otherwise WSfact_i,j = min(WSfactH_i,j, WSfactN_i,j) Mixed-canopy transpiration stress: WStressTMC_j = 1 if ContrainteW_j > PfactorMC WStressTMC_j = ContrainteW_j / PfactorMC otherwise TranspiMC_j = TPotMC_j * WStressTMC_j Severe drought signal: SignalFletrissement_j = SignalFletrissement_j-1 + 1 if Stnonrac_j <= 0.0001 and Strac_j <= 0.02 SignalFletrissement_j = 0 otherwise

2.9 Soil Nitrogen Balance

Soil temperature proxy: Tsoil_j = Tmoy_j Mineralization of soil organic N: KnMin_j = 24 * exp(17.753 - 6350.5 / (Tsoil_j + 273)) Tfact_j = 1 - exp(-KnMin_j / 168) Wfact_j = 1.111 * ContrainteWSurf_j if ContrainteWSurf_j < 0.9 Wfact_j = 10 - 10 * ContrainteWSurf_j otherwise Wfact_j = max(Wfact_j, 0) Nmin_j = Nhum_j-1 * Tfact_j * Wfact_j Nmin_j = Nmin_j * (0.0002 - ConcNsol_j) / 0.0002 * 10 Nmin_j = max(Nmin_j, 0) Denitrification: KDenit_j = 6 * exp(0.07735 * Tsoil_j - 6.593) NDenit_j = XConcNsol_j * (1 - exp(-KDenit_j)) * Stsurf_j * 1000 * 10 Applied organic matter branch (unfinished in code): FTR_j = 12 / (1 + 51.6 * exp(-0.103 * Tsoil_j)) FH_j = 0.2 + 0.8 * ContrainteWSurf_j DNMinOrg_j = -DNres_j - DNhum_j - DNbio_j Available mineral N: Navail_j = Navail_j-1 + Nmin_j + AppMinN_j - 0.35 * AppMinN_j + DNMinOrg_j - perteNDrain_j - NuptMC_j - 0.01 * Navail_j-1 - NDenit_j Navail_j = max(Navail_j, 0) Solution concentration and drainage loss: VolEausol_j = ZracmaxMC_j * TAW ConcNsol_j = Navail_j / VolEausol_j perteNDrain_j = ConcNsol_j-1 * Dr_j

5. Caveats

Interpretation status. This V32 revision is derived from the generated VB.NET implementation and the matching VBA export. It is intentionally close to the code, not to an idealized formulation.
  • The organic matter mineralization routine for applied residues, MinNorgapporteStics, is marked unfinished in comments. V32 supplies residue parameters through ListResidus, but the formulation still requires scientific validation.
  • V32 reads mean atmospheric CO₂ from ListPAnnexes and replaces it with the matching simulation-year value from CO2Yearly when available; crop response is calculated by the existing FCO2 formulation.
  • The soil water model behaves mainly as a bucket formulation even though a layered schema exists in the database.
  • Soil temperature in the N module is currently approximated by mean air temperature.
  • The competition logic for mixed canopies is implemented but acknowledged in comments as needing cautious validation.
  • Recursive multi-simulation behavior exists in the controller but is only partially operational in the current port.
